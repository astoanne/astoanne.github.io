为什么 E[X + Y] = μ₁ + μ₂，而不是 √(μ₁² + μ₂²)

X ~ N(μ₁, σ₁²)，Y ~ N(μ₂, σ₂²)，Z = X + Y。下图是 (X, Y) 的联合密度山丘。 竖直切面 x + y = z 每切一刀，对应 Z 取一个值；穿过山顶的那一刀，就是 Z 的中心。

ρ 是 X 与 Y 的相关系数，默认 0 即独立。改变 ρ 会让山丘变成斜的椭圆，但山顶和金色切面的位置不变。

这几个中心到原点的距离都是 5，Z 的均值却各不相同：

这个几何论证分三步

  1. 距离 5 和 X + Y 回答的是两个不同的问题

    √(x² + y²) 问的是“点离原点多远”；x + y 问的是“点沿 (1,1) 方向走了多远”。 底面上，到原点距离为 5 的点组成红色虚线圆；x + y = 7 的点组成金色直线。 (3, 4) 恰好同时落在两者上，可同在圆上的 (5, 0) 的 x + y 是 5，(3, −4) 的是 −1。 只知道距离，推不出 X + Y。

  2. x + y 是沿 (1,1) 方向的坐标，再乘 √2

    取单位向量 u = (1,1)/√2。点 (x, y) 在 u 上的正交投影长度是 (x + y)/√2，所以 x + y = √2 × 投影坐标。 直线 x + y = c 与 (1,1) 垂直，它上面的每个点都投影到对角线上的同一点 (c/2, c/2)。 对角线上的刻度就是一把“Z 尺”：刻度间距 1/√2，标的是 Z 值。 中心 (3, 4) 投影到 (3.5, 3.5)，投影长度 7/√2，乘 √2 得 7。

  3. 切面扫过山丘，扫出的就是 Z 的分布

    竖直平面 x + y = z 在山丘上切出一条剖面，剖面面积 = √2 · fZ(z)（右侧有数值核对）。 联合密度关于中心 (μ₁, μ₂) 点对称，所以 z = μ₁+μ₂+t 与 z = μ₁+μ₂−t 两刀切出的剖面互为镜像， fZ 关于 μ₁+μ₂ 对称。Z 的中心，就是穿过山顶的那一刀。 这里只用到了中心的位置，不需要独立：把 ρ 调成非零，金色切面仍然穿过山顶。

那 √(·² + ·²) 真正属于谁？

属于标准差。X、Y 独立时 Var(Z) = σ₁² + σ₂²，所以 σZ = √(σ₁² + σ₂²)——这种“勾股”形式描述的是山丘有多宽，不是山顶在哪。 均值永远线性相加：E[X + Y] = E[X] + E[Y]。代数上 (μ₁ + μ₂)² = μ₁² + μ₂² + 2μ₁μ₂， 两者只差交叉项 2μ₁μ₂，只有 μ₁ 或 μ₂ 为 0 时，欧氏距离才碰巧等于 |μ₁ + μ₂|（试试预设 (5, 0)）。
