01 · Start here

实习生第一周，只做三件事

不要一上来“运营四个平台”。先搭好可重复的最小系统：一个受众、一批来源、一个能追踪的落地页。

STEP 01

把对象说具体

每条内容开工前先填一句：

  • 谁：海外采购商 / 国际馆展商 / 首次来华团队
  • 何时：出发前 / 到达日 / 展中 / 工厂考察 / 展后
  • 行业：三期中的一个小类
STEP 02

建立 20 个可靠来源

小红书、知乎、抖音只负责“发现问题”；日期、交通、办证、酒店、政策必须回到官方来源复核。

  • 广交会官网与当届海外买家指南
  • 机场、地铁、政府、酒店官网
  • 行业协会与监管机构
STEP 03

统一服务入口

资料型帖子也要能回到同一个页面，但不要每段都卖服务。

  • 链接统一指向译员浏览页
  • 每个平台使用独立 UTM
  • CTA 写动作：“Browse interpreters by language”

02 · Channels

四个平台，四种任务

同一个主题可以复用，但不能原文复制。LinkedIn 建信任，X 抢时效，YouTube 吃搜索，Facebook 进社群。

B2B / TRUST

LinkedIn

主阵地：决策人信任

  • 每周 2 条：实用清单 + 行业洞察
  • 优先 PDF 轮播、现场照片、短原生视频
  • 由真实员工账号参与评论，不刷模板
  • 内容写给采购、销售负责人、参展负责人

固定配方：痛点钩子 → 3–5 条清单 → 中国现场细节 → 一个问题 → 软 CTA

REAL-TIME / REPLIES

X

雷达：及时提醒与对话

  • 每周 3 条短帖或 1 条 5–7 段线程
  • 围绕 #CantonFair、行业词与 Guangzhou
  • 展期发入口、天气、交通、排队变化
  • 每天主动回复 5 个真实参展问题

固定配方：一句突发/误区 → 3 个要点 → 官方来源 → 轻量链接

SEARCH / HOW-TO

YouTube

内容资产：长期搜索流量

  • 每周 1 条 Short；每两周 1 条 3–6 分钟指南
  • 不会拍就用地图/网页录屏 + 英文旁白
  • 一个视频只回答一个搜索问题
  • 标题写用户会搜的完整问题

固定配方：5 秒答案 → 3 个步骤 → 屏幕示范 → 描述区清单与落地页

GROUPS / COMMUNITY

Facebook

社群：在华外商与行业群

  • 先读群规，先回答，再发自己的内容
  • 每周 1 个长帖 + 3–5 次有用评论
  • 适合酒店、支付、交通、现场求助类内容
  • 避免把同一推广链接丢进多个群

固定配方：明确人群 → 可保存清单 → 邀请补充 → 群规允许时再放链接

03 · Content engine

中文平台不是素材仓库，是“问题雷达”

延续现有 Claude content-pipeline 的核心纪律：不同平台要重新写，事实不足就留待确认，不能靠“翻译得像真的”补齐。

01 / LISTEN

发现问题

在小红书、知乎、抖音、展商群搜“广交会 + 第一次 / 机场 / 酒店 / 付款 / 工厂”。只记录问题与关键词。

02 / VERIFY

回官方核验

用当届官方指南、机场/地铁/酒店官网确认日期、地点、价格与规则。截下来源链接和更新日期。

03 / ADD VALUE

加入本地经验

补上外国人真正会卡住的步骤、英文说法、地图顺序、现场沟通点。不要只做直译。

04 / REMAKE

四种原生版本

LinkedIn 做清单，X 做提醒，YouTube 做演示，Facebook 做讨论。开头、长度、CTA 都不同。

05 / LEARN

记录与复用

保存原问题、官方来源、英文稿、链接、数据。有效主题 30 天后换角度再发，而不是作废。

版权与可信度底线：不要下载并重发原作者的视频/图片，不要逐句翻译整篇帖子。提炼问题后自己重新研究、重新组织、自己做图，并在涉及规则时链接官方来源。
04 · Phase strategy

三期不是三个日期，是三群不同的人

总攻略只能吸引一次点击；行业化内容才能让海外团队觉得“这家公司懂我们的生意”。

05 · Idea bank

选题库：拿一个就能开工

先按阶段筛，再按标题做。每张卡都给出最小成品，避免“搜了两小时还没开始写”。

没有匹配项。换一个更短的关键词试试。
06 · Anti-stuck system

每天 90 分钟，做到“可以发布”

任务结束条件不是“研究得差不多”，而是有一条已核验、已改写、带来源、带下一步的成品。

单条内容时间盒

15m找问题只收集 3 个候选，选最具体的一个，不继续刷。
20m核事实找到 1–3 个权威来源，记下发布日期与链接。
25m写主稿先写 LinkedIn 或 YouTube 主稿；一个问题、三到五个要点。
15m做素材一张清单图，或 30–60 秒录屏。没有图也不拖延。
10m质检发布检查数字、人名、链接、英文、CTA 与平台规则。
05m登记在台账记标题、平台、UTM、发布日期；次日回填数据。

卡住时，立刻降级

找不到完整资料？改成“3 个你出发前要向官方确认的问题”，不要编答案。
英文写不顺？先写 5 条事实清单，再让 AI 改成自然英文；逐条反查含义。
不会做视频？地图/官网录屏 + 旁白 + 自动字幕，就是合格 Short。
没有新选题？从客户聊天、评论区和搜索自动补全中取一个真实问题。
不敢发？使用下方红黄绿审核：绿色直接发，黄色核验后发，红色交负责人。
